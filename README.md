## Features
- contacts list sorted A-Z with section index
- search by name or number
- add, edit and delete contacts
- swipe left to delete, swipe right to favorite
- contact detail screen with call button
- recents tab with call history (all / missed)
- favorites shown in a grid

## Built with
- Swift, UIKit
- UITableView, UICollectionView
- Auto Layout (all in code, no storyboard)
- UINavigationController + UITabBarController

## Run
Open `ContactsApp.xcodeproj` in Xcode, pick an iPhone simulator and press Cmd+R.

Note: data is kept in memory for now, so it resets when the app restarts.
